# Geisel Library 与 Snake Path：场景参考研究

核实日期：2026-09-30（America/Los_Angeles）。本文件依据公开建筑资料和照片整理 Geisel Library 与 Snake Path 的复原依据，区分已证实事实与重建时的推定。

## 已核实的建筑特征

- 建筑师：William L. Pereira & Associates；1970 年启用。现名纪念 Audrey 与 Theodor Geisel。
- UC San Diego 图书馆当前官网给出：**8 个层级，高 110 ft = 33.528 m，最大跨度 248 ft = 75.5904 m**。官网把下两层称为 pedestal，上方为六层阶梯式 tower；这包括开放 forum，实际悬空藏书楼层是 4–8，共五层。
- 建筑在校园中央、**峡谷的谷头**；不是孤立的山峰。两层基座和之后的地下扩建顺应坡地。南面为主要入口和 Library Walk 方向。
- ArchDaily 明确记载：**第六层最宽**，上、下楼层向中心逐层收小；中央电梯/楼梯核心贯穿建筑；**16 根外露混凝土支柱**从 forum 向外以约 45° 展开，承托至第六层下缘。
- 原建筑图显示楼板平面是四向对称的**阶梯十字/阶梯菱形轮廓**，不是每层一块简单正方形。四个方向各有四根主要支柱。台阶状外围空间对应梁的分段支撑。
- 1969 年原报告第 53 页含南立面与剖面，第 59 页含核心筒与开放 forum 的说明。报告文字直接称有 sixteen great concrete bents。
- 立面最有识别度的细节：外露板纹混凝土、成排外挑斜柱、楼板下方密集格梁/肋梁、稍翘起的薄檐口、竖向细框与大面积冷蓝灰反光玻璃。玻璃反射天气与天空，色彩会随时间变化。

尺寸口径注意：1969 年原报告第 62 页**直接**把第三藏书层（现第六层）写为 “some 200 feet in diameter”，即约 **60.96 m**；第 61 页把第二藏书层（现第五层）写为 “approximately 150 feet across”，即约 **45.72 m**；第 64 页说明第四藏书层（现第七层）与第二藏书层尺寸和形状相同。这些不是二手资料猜测。当前官网的 248 ft = 75.5904 m 是建筑整体最大跨度，未说明是否包含基座、平台与挑檐；因此不能直接把它当作六层净楼板宽度。建议使用原报告的逐层信息校准塔体，并把两种尺寸口径明确区分。没有逐根支柱测绘数据。

## 已核实的 Snake Path 形态与空间关系

- 艺术家 **Alexis Smith**，作品 **Snake Path，1992**。官方位置为 **Geisel Library 东侧到 Warren Mall**。
- 总长 **560 ft = 170.688 m**；宽 **10 ft = 3.048 m**。这是一条巨蛇形状的可步行公共艺术，不是普通砂石登山小径。
- **西端高处**靠近图书馆的蛇头嵌在混凝土 terrace 里，叉舌伸向馆前平台。身体盘绕一个近完整的圆环，围住 Garden of Eden；向**东侧低处**下行，经 Paradise Lost 石书；尾巴在坡下缠绕原有混凝土步道。
- 官方平面图 `References/smith-a-01.jpg` 清楚显示：图书馆在图上方，先见蛇头，再见花园盘绕，随后路径横向转弯再长曲线下坡，尾端与步道交缠。图中无北箭头，因此只可依据“图书馆在西端”推断图上约为西、图右约为北；精确角度未经地理配准。
- 路中央略高，断面有轻微圆拱（crowned），是作品的身体感的重要部分，不能做成完全平坦的普通路面。
- 自然板岩切成可随方向变化的狭长六边形鳞片；艺术家访谈说有约 **7,000 块**，三种板岩、三种大小，源自中国、非洲和印度，形成不重复的响尾蛇式斑纹。基础方料约 12 inch。
- 实拍可见板岩为浅沙灰、暖褐/淡粉灰及深灰蓝色；斑纹应呈大尺度连续图案。不得把路径整体设成艳绿或单一无纹理颜色。
- Eden 花园包括苹果、无花果、石榴；官方正文也提及棕榈，实景照片显示数棵非常狭长的柱状常绿树、低灌木、小果树，内有一张弧形石凳。小花园被蛇身围合，其石板脚踏路径区别于外圈蛇鳞。
- 石书约 **7 ft = 2.1336 m 高**，直立的大型花岗岩书；红褐色封面配浅色蚀刻卷草，灰白书页侧边，书脊略圆。书不是摊开的书，也不是全白的大理石碑。
- 蛇坡不是天然未扰动地形：它是在 1990 年代地下扩建上方塑出的人工山坡，坡形和蛇路在现场相互调整。周围使用与峡谷相似的本地植被。
- 现场背景有较高的桉树林，坡面多干土、草本、低矮灌木；少量校园维护草坪位于上平台边缘和 Warren Mall。整座坡面不应铺成均匀鲜绿草坪。

## 场景重建的合理推定（不是实测数据）

- 世界轴约定：X 向东，Y 向北，Z 向上；建筑中心为 (0,0)。蛇路与 Warren Mall 在正 X 方向，东端更低。建筑所在台地与坡下高差、路径精确平面坐标、局部树高需要依据视觉匹配估计；当前未取得 LiDAR 或实测高程，不宣称厘米级复原。
- 结合原报告，可把 5/6/7 层的近似宽度约束为 **45.72 / 60.96 / 45.72 m**；4/8 层约为 34 m 仍是从图纸轮廓读出的比例推定。应把楼板、支柱外缘、悬挑、檐口及不同深度的立面区分开。原报告第 60、61、62、64、65 页分别展示五个塔层，逐层角部退台数量不同，不能直接等比缩放同一个平面。
- 六层平面最大端面中央直线段约为总跨宽的 40%，两侧以数级直角台阶退缩，形成截角阶梯十字形。精确折点和每层变化应通过图像比对，而非把整体仅缩放五次。
- 花园圈的大小按原设计图和 `smith-a-02.jpg` 实拍作视觉估计。蛇身在花园西侧与自身相接，铺装应形成完整围合；这里不能出现折返造成的断头、尖角或分离的路面。相接区域使用连续的合并铺装，花园内部保持为一个独立的种植区。
- 可选择晚日下午或上午晴天，并保留可调时间/太阳角度。只有采用真实地点、日期与时间的太阳位置公式时，才应给灯光标注具体时刻；任意美术灯位应标为艺术调光。

## 光照与材料参考

- 坐标用于太阳计算可取约 32.88116° N, 117.23765° W（公开地理坐标，非测量控制点）。当地时区为 America/Los_Angeles。
- 从东侧蛇路看向西面的 Geisel，下午太阳逐渐在建筑后侧，呈逆光/侧逆光；不应同时声称“傍晚西晒”又让东侧立面均匀受正面暖光。可保留天空填充、混凝土反弹及玻璃反射，让主体不死黑。
- 上午太阳在东侧，适合从蛇路看到受光的图书馆东立面；晚下午强调长阴影、暖色边缘及冷色天空反射。
- 混凝土基色偏中浅暖灰，表面较粗糙，有板模横纹、细斑点和局部雨痕；玻璃镜面但不是纯铬，反射天空蓝灰与植被。檐下和格梁间的遮蔽是厚重感的主要来源。
- 南加州的晴空强直射光与明确阴影是常见情境，海岸薄雾/蓝色远景空气透视可轻微加入；这只是天气情境选择，并非对拍摄当天的历史气象重演。
